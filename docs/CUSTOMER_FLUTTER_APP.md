# Customer Flutter App

The Flutter application lives at `apps/customer_flutter/` and uses the existing public directory API. Follow `apps/customer_flutter/README.md` for SDK requirements, API URL configuration, tests and Android build commands.

No production deployment credentials are needed during the build phase. The API URL is a public endpoint configuration, not a secret. Use HTTPS for release builds. Favorites are local-only until a versioned authenticated favorites endpoint is approved and implemented.
