# Creatarsh human/editorial redesign

This update refreshes the public-facing Creatarsh company website with a warmer, more personal editorial design.

## What changed
- Rebuilt the homepage around a human, conversational message and a more distinctive editorial layout.
- Added original CSS-built interface/product compositions to avoid generic placeholder cards and stock-looking hero art.
- Reworked the service catalogue into clear service areas and practical deliverables.
- Rewrote the About page with a more grounded, founder-led studio voice without inventing client claims or team credentials.
- Reworked Contact around three direct ways to start a conversation.
- Updated selected-work page copy so product concepts and demonstrations are not misrepresented as completed client commissions.
- Added a shared warm-white, forest-green design system with DM Sans and DM Serif Display typography, more varied layouts, lighter borders and responsive behavior.

## Preserved
- Existing Express backend and API routes.
- Manager and customer account areas.
- Existing login, registration, package, order and payment integrations.
- Existing legal pages, product tools, and customer-side scripts.

## Notes
- No production deployment was performed.
- The project ZIP excludes local `.env` secrets and `.git` history. Configure the server using `server/.env.example`.
- Dynamic package, product and portfolio content still depends on the configured backend/API.
